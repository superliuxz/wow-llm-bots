# Karazhan (Kara)

## Shade of Aran

- **Arcane Explosion**: boss cast; follow standing order (`out of it, then back`).

```
Arcane Explosion cast -> out of it, then back
```

## Conjured Elemental

- **Conjured Elemental**: priority add; switch and burn promptly.

```
Conjured Elemental appears -> target nearest Conjured Elemental
```

## Netherspite

- **Void Zone**: ground hazard; move out immediately.

```
in Void Zone -> out of it
```

## Prince Malchezaar

- **Netherspite Infernal**: unkillable Hellfire hazard; stay clear (`away Netherspite Infernal 16`).

```
Netherspite Infernal within 12 -> away Netherspite Infernal 16
```
