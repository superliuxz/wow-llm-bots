# Icecrown Citadel (ICC)

## Lord Marrowgar

- **Coldflame**: moving line of blue fire; move out immediately.
- **Bone Spike Graveyard**: impales players on **Bone Spike** targets; switch and destroy Bone Spikes immediately.
- **Bone Storm**: boss spins and deals heavy melee AoE while moving; move away from Marrowgar during Bone Storm.

```
in Coldflame -> out of it
Bone Spike appears -> target nearest Bone Spike
Bone Storm cast -> away Lord Marrowgar 15
```


## Lady Deathwhisper

- **Vengeful Shade**: react immediately (`away Vengeful Shade 15`).

```
Vengeful Shade appears -> away Vengeful Shade 15
```

## Deathbringer Saurfang

- **Blood Beast**: priority add; switch and burn promptly.

```
Blood Beast appears -> target nearest Blood Beast
```

## Rotface

- **Unstable Ooze Explosion**: cast by Big Ooze; move out immediately and return once safe (`out of it, then back`).
- **Vile Gas**: ground hazard; move out immediately.

```
Unstable Ooze Explosion cast -> out of it, then back
in Vile Gas -> out of it
```

## Volatile Ooze

- **Volatile Ooze**: priority add; switch and burn promptly.

```
Volatile Ooze appears -> target nearest Volatile Ooze
```

## Gas Cloud

- **Gas Cloud**: stay clear (`away Gas Cloud 14`).

```
Gas Cloud within 10 -> away Gas Cloud 14
```

```
in Slime Puddle -> out of it
```

## Prince Keleseth

- **Dark Nucleus**: priority add; switch and burn promptly.

```
Dark Nucleus appears -> target nearest Dark Nucleus
```

## Prince Valanar

- **Empowered Shock Vortex**: boss cast; follow standing order (`out of it`).

```
Empowered Shock Vortex cast -> out of it
```

## Blood Prince Council

- **Kinetic Bomb**: priority add; switch and burn promptly.
- **Ball of Flames Visual**: unempowered chasing flame orb summoned by Prince Taldaram; stay clear (`away Ball of Flames Visual 16`). Empowered orbs pulse **Empowered Flare** (`10 yd`); soak briefly if assigned to shrink their explosion before impact.

```
Kinetic Bomb appears -> target nearest Kinetic Bomb
Ball of Flames Visual within 12 -> away Ball of Flames Visual 16
```

## Valithria Dreamwalker

- **Blistering Zombie**: fixates on you; kite it.

```
Blistering Zombie targets me -> kite it
```

## Sindragosa

- **Ice Tomb**: damage tombs down to ~50% HP and hold them for line-of-sight cover during Frost Bomb before finishing them.
- **Blistering Cold**: boss cast; follow standing order (`out of it`).

```
Ice Tomb appears & Ice Tomb hp>50 -> target nearest Ice Tomb
Blistering Cold cast -> out of it
```

## The Lich King

- **Quake**: boss cast; move to 40 yd from the boss to stay on the safe inner platform ring (`to 40 yd from boss`).

```
Quake cast -> to 40 yd from boss
```
