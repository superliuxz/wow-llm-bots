# Tempest Keep (TK)

## Shared

- **Lord Sanguinar**: priority add; switch and burn promptly.

```
Lord Sanguinar appears -> target nearest Lord Sanguinar
```

## Solarium Agent

- **Solarium Priest**: priority add; switch and burn promptly.

```
Solarium Priest appears -> target nearest Solarium Priest
```

## Thaladred the Darkener

- **Thaladred the Darkener**: fixates on you; kite it.

```
Thaladred the Darkener targets me -> kite it
```

## Kael'thas Sunstrider

- **Flame Strike**: ground hazard; move out immediately.
- **Phoenix Egg**: priority add; switch and burn promptly.
- **Gravity Lapse**: debuff on you; follow standing order (`away group 10`).

```
in Flame Strike -> out of it
Phoenix Egg appears -> target nearest Phoenix Egg
Gravity Lapse on me -> away group 10
```
