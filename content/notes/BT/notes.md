# Black Temple (BT)

## Supremus

- **Supremus**: fixates on you; kite it.

```
Supremus targets me -> kite it
```

## Shade of Akama

- **Ashtongue Channeler**: priority add; switch and burn promptly.

```
Ashtongue Channeler appears -> target nearest Ashtongue Channeler
```

## Teron Gorefiend

- **Shadowy Construct**: priority add; switch and burn promptly.

```
Shadowy Construct appears -> target nearest Shadowy Construct
```

## Illidan Stormrage

- **Parasitic Shadowfiend**: priority add; switch and burn promptly.
- **Demon Fire**: ground hazard; move out immediately.
- **Shadow Demon**: priority add; switch and burn promptly.
- **Flame of Azzinoth**: priority add; switch and burn promptly.

```
Parasitic Shadowfiend appears -> target nearest Parasitic Shadowfiend
in Demon Fire -> out of it
Shadow Demon appears -> target nearest Shadow Demon
Flame of Azzinoth appears -> target nearest Flame of Azzinoth
```
