# Drak'Tharon Keep (DTK)

## Trollgore

- **Drakkari Invader** (add_switch): Priority add; switch targets to `Drakkari Invader` immediately.

```
Drakkari Invader appears -> target nearest Drakkari Invader
```

## Novos the Summoner

- **Arcane Field** (ground_hazard): Ground hazard; move out immediately.

```
in Arcane Field -> out of it
```

## The Prophet Tharon'ja

- **Gift of Tharonja** (debuff): Aura `Gift of Tharonja` on me; hand-check encounter reaction.

## Drak'Tharon Keep

- **Crystal Handler** (add_switch): Priority add (`NPC_CRYSTAL_HANDLER`); switch and burn immediately.

```
Crystal Handler appears -> target nearest Crystal Handler
```
